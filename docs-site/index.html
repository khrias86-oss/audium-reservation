    지금 감시 중

      자동 등록을 켜면 여기에서 바로 확인할 수 있습니다.

      내 예약 정보

      자리가 났을 때 타이핑하지 않고 붙여넣기만 하려고 미리 적어 두는 칸입니다. 이 브라우저에만 저장되고 어디로도 전송되지 않습니다.

      💡 아이폰이라면 설정 → Safari → 자동 완성 → 내 정보에 연락처를 지정해 두세요. 오디움 예약 화면에서 이름·이메일·휴대폰이 한 번에 채워집니다. 이 칸보다 훨씬 빠릅니다.

      자동 등록

      토큰 만드는 법 (한 번만 하면 됩니다)
      1. GitHub 토큰 만들기 화면 열기
      2. Repository access에서 Only select repositories → 이 저장소를 고릅니다
      3. Repository permissions → Issues 를 Read and write 로 바꿉니다
      4. 같은 목록의 Actions 를 Read-only 로 바꿉니다 (마지막 확인 시각을 보려고)
      5. Generate token → 나온 값을 복사해 위 칸에 붙여넣습니다

      토큰은 이 브라우저에만 저장되고 github.com 외에는 전송되지 않습니다. 권한도 이 저장소의 신청서(Issues)를 읽고 쓰는 것뿐이라, 코드나 다른 저장소는 건드릴 수 없습니다. 언제든 해제를 누르면 지워집니다.
