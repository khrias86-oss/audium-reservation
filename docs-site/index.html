    이 기기에서 신청한 알림

      다른 기기에서 신청한 알림은 메일의 "그만 받기" 링크로 끌 수 있습니다.

      알림이 오면 — 1분 안에 예약하는 법

      • 취소표는 몇 분 안에 다시 나갑니다. 알림을 보면 바로 예약 화면을 여세요.
      • 오디움은 1인 1매, 본인 휴대폰 인증이 필요합니다. 함께 갈 사람은 각자 신청·예약하세요.
      • 휴대폰 자동완성에 이름·이메일·전화번호를 넣어 두면 입력이 한 번에 끝납니다.
        아이폰: 설정 → Safari → 자동 완성 → 내 정보 / 안드로이드: Chrome → 설정 → 주소 및 기타 정보
      • 한가할 때 한 번 끝까지 눌러 보세요 (인증 직전까지). 실제 때 헤매지 않습니다.
