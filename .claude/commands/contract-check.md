---
description: 저장된 사이트 계약과 실제 사이트를 대조해 드리프트를 검출한다
---

`docs/site-contract.md`에 기록된 계약이 여전히 유효한지 검증한다.

1. 계약에 적힌 각 엔드포인트를 1회씩만 호출한다 (반복 금지)
2. 응답을 `src/adapters/audeum/schema.ts`의 Zod 스키마로 검증한다
3. DOM 셀렉터가 계약에 있다면 Playwright로 존재 여부를 확인한다
4. 불일치를 표로 보고한다: 계약값 / 실제값 / 영향받는 코드 위치

드리프트가 발견되면 코드를 고치기 전에 **먼저 사용자에게 보고**하라.
사이트 개편은 파싱 로직뿐 아니라 예약 절차 자체가 바뀌었을 수 있다.
