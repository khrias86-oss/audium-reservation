# 배포처 선택

## 결론

**1순위: Google Cloud Run + Cloud Scheduler + Neon Postgres**
(대시보드 = Cloud Run 서비스, 워커 = Cloud Scheduler가 10분마다 호출하는 Cloud Run 잡)

단, 이 저장소는 **어느 플랫폼에도 결합되어 있지 않다.** 하나의 이미지가 두 모드로 돌고
(`MODE=server` / `MODE=tick`), 스케줄링을 플랫폼에 맡기든 프로세스 안에서 돌리든
같은 코드가 쓰인다. 배포처가 마음에 안 들면 `Dockerfile`을 다른 곳에 올리면 끝이다.

## 검토 결과

| 후보 | 판정 | 근거 |
|---|---|---|
| **Vercel Hobby** | ❌ 탈락 | Cron이 **하루 1회**가 최대이고 실행 시각도 1시간 이내 보장. `*/10 * * * *`은 배포 시점에 거부된다 |
| **Render 무료** | ❌ 탈락 | 백그라운드 워커와 크론 잡이 **유료 전용**. 무료는 웹 서비스 750시간/월뿐이고 15분 유휴 시 슬립 |
| **Fly.io** | ❌ 탈락 | 2026년 기준 무료 티어 없음 (2 VM-시간 또는 7일 체험만) |
| **Oracle Always Free** | ⚠️ 위험 | 2026년 6월부터 ARM이 **2 OCPU/12GB로 반감**. 더 큰 문제는 **유휴 회수** — 7일간 CPU 95백분위가 20% 미만이면 인스턴스를 회수한다. 10분에 한 번 깨는 워커는 정확히 그 조건에 걸린다 |
| **GitHub Actions** | ⚠️ 조건부 | private 저장소는 월 2,000분. 10분 주기 = 월 4,320회이고 분 단위 반올림 과금이라 초과. public 저장소면 무제한이지만 저장소를 공개해야 한다 |
| **Cloud Run + Scheduler** | ✅ 채택 | 아래 예산 계산 참조 |

## Cloud Run 무료 한도 예산

무료 한도(미국 일부 리전): **vCPU 180,000초/월**, **메모리 360,000 GiB-초/월**, 요청 200만 건/월.
Cloud Scheduler는 **잡 3개까지 무료** (우리는 1개 사용).

10분 주기 = 144회/일 × 30일 = **4,320회/월** 기준:

| 경로 | 틱당 사양 | vCPU 사용 | 메모리 사용 | 여유 |
|---|---|---|---|---|
| **A** (JSON API, 브라우저 불필요) | 0.5 GiB · 5초 | 21,600초 (12%) | 10,800 GiB-초 (3%) | 매우 넉넉 |
| **B** (Playwright 필요) | 2 GiB · 25초 | 108,000초 (60%) | 216,000 GiB-초 (60%) | 40% 여유 |

**최악의 경우(경로 B)에도 무료 한도 안에 들어온다.** 여유가 부족해지면 폴링을
한국 활동 시간대(08~23시)로 제한하면 사용량이 약 40% 줄어든다.

대시보드는 scale-to-zero라 사용자가 열 때만 과금되고, 콜드스타트(수 초)는
대시보드 용도에 문제되지 않는다.

**주의**: 무료 한도는 미국 일부 리전에만 적용된다. 한국(asia-northeast3)에
배포하면 무료 한도를 못 받는다. 지연은 이 용도에서 무의미하므로 **us-central1** 등을 쓴다.

## 상태 저장

Cloud Run은 상태를 갖지 않으므로 감시 조건·스냅샷·서킷·하트비트·멱등성 키를
외부 DB에 둔다. **Neon 무료 Postgres**를 쓴다 (서버리스, GCP 비용과 무관).
`src/store/types.ts`의 `Store` 포트만 구현하면 되고, 나머지 코드는 바뀌지 않는다.

## 필요한 계정

- Google Cloud 계정 (무료 한도 사용에도 **결제 카드 등록 필요**, 한도 내에서는 과금 없음)
- Neon 계정 (카드 불필요)
- Resend 계정 (이메일 발송, 무료 3,000통/월) 또는 Gmail 앱 비밀번호

## 대안 경로

카드 등록을 원치 않는다면:

1. **사용자 PC 상시 실행** — `MODE=server`로 띄우고 내부 스케줄러로 폴링.
   가장 단순하고 계정이 필요 없다. PC가 꺼지면 감시가 멈추는 것이 유일한 단점이며,
   하트비트 경고가 그 사실을 즉시 드러낸다.
2. **저장소를 public으로 전환 후 GitHub Actions** — 무료 무제한. 예약자 개인정보는
   GitHub Secrets에 두고 로그에서 마스킹한다.
