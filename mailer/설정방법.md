# 가족 알림 설정 (한 번만, 약 10분)

가족이 **공개 페이지에 메일 주소만 넣으면** 빈자리·예약 오픈 알림을 받게 하는 설정입니다.
메일은 **본인 Gmail에서** 나가고, 가족 주소는 본인 Google 계정 안에만 저장됩니다.
GitHub 저장소(공개)에는 주소도 비밀번호도 남지 않습니다.

준비물: 본인 Google 계정, GitHub 저장소 설정 권한.

---

## 1. 코드 두 개 만들기

관리자 화면 **https://khrias86-oss.github.io/audium-reservation/#admin** 의
**"가족 초대 링크 만들기"** 에서 **[무작위 코드 만들기]** 를 누르면 두 값이 나옵니다.

- **초대 코드** — 가족 초대 링크에 들어갑니다 (가족만 알면 되는 값)
- **알림 열쇠** — GitHub만 알면 되는 값입니다. 가족에게 보내지 마세요

이 화면은 그대로 열어 두세요. 아래에서 두 값을 복사해 씁니다.

## 2. Google Apps Script에 발송기 올리기

1. **https://script.google.com** → **새 프로젝트**
2. 왼쪽 위 제목을 **오디움 메일 발송기** 로 바꿉니다
3. 편집기의 내용을 모두 지우고, 아래 파일 내용을 그대로 붙여넣은 뒤 **저장(💾)**
   - https://github.com/khrias86-oss/audium-reservation/blob/main/mailer/Code.gs
     (파일 오른쪽 위 **복사** 버튼)
4. 왼쪽 **⚙️ 프로젝트 설정** → 맨 아래 **스크립트 속성 추가** 를 두 번:
   | 속성 | 값 |
   |---|---|
   | `INVITE_CODE` | 1단계의 **초대 코드** |
   | `NOTIFY_KEY` | 1단계의 **알림 열쇠** |
5. 왼쪽 **< > 편집기** → 위쪽 함수 목록에서 **authorize** 선택 → **▶ 실행**
   - "권한 검토" → 본인 계정 선택
   - "Google에서 확인하지 않은 앱" 화면이 나오면 **고급** → **오디움 메일 발송기(으)로 이동** → **허용**
     (본인이 만든 스크립트라 나오는 안내입니다)
   - 본인 메일함에 **"오디움 메일 발송기 권한 확인"** 메일이 오면 성공
6. 오른쪽 위 **배포 → 새 배포**
   - 톱니(⚙️) → **웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포** → 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사

> "모든 사용자"여도 안전합니다. 메일 등록은 **초대 코드**가, 알림 발송은 **알림 열쇠**가
> 있어야만 됩니다. 가족 주소 목록은 밖으로 돌려주지 않습니다.

## 3. GitHub에 알려주기 (시크릿 3개)

**https://github.com/khrias86-oss/audium-reservation/settings/secrets/actions** →
**New repository secret** 을 세 번:

| Name | Secret |
|---|---|
| `MAILER_URL` | 2-6의 **웹 앱 URL** |
| `MAILER_KEY` | 1단계의 **알림 열쇠** |
| `NTFY_TOPIC` | 관리자 화면에 표시된 **푸시 채널 이름** (`audeum-` 로 시작) |

## 4. 가족 초대 링크 만들기

관리자 화면의 **"가족 초대 링크 만들기"** 에 **웹 앱 URL**을 붙여넣으면 초대 링크가 만들어집니다.
**[카톡으로 보내기]** 를 눌러 가족에게 보내세요.

가족은 링크를 열고 **메일 주소를 넣고 [등록]** 만 누르면 됩니다.
확인 메일이 오면 끝입니다. 휴대폰 푸시를 원하면 같은 화면의 안내대로 ntfy 앱을 설치합니다.

## 알아두실 것

- **하루 메일 한도:** 개인 Gmail은 Apps Script로 하루 약 100통까지 보낼 수 있습니다.
  가족 2~3명이면 넉넉합니다.
- **코드를 고치면:** Apps Script에서 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포**.
  웹 앱 URL은 그대로 유지됩니다.
- **누가 등록돼 있나:** Apps Script **프로젝트 설정 → 스크립트 속성**의 `SUBSCRIBERS`에 있습니다.
  지우려면 그 목록에서 주소를 빼면 됩니다.
- **초대 코드가 퍼졌다면:** `INVITE_CODE`를 새 값으로 바꾸고 새 초대 링크를 보내면 됩니다.
  이미 등록된 가족에게는 영향이 없습니다.
