# 알림 서버 설정 (한 번만, 약 10분)

공개 페이지에서 **누구나 날짜·회차를 고르고 메일 주소를 넣으면** 빈자리 알림을 받게 하는 설정입니다.

```
신청자 ──(페이지에서 신청)──▶ 알림 서버 ──▶ 구글 시트 (신청 목록)
                              (내 Google 계정의 Apps Script)
GitHub Actions ──(5분마다: 볼 회차를 묻고, 본 결과를 넘김)──▶ 알림 서버 ──▶ 신청자에게 메일 · 푸시
```

- 메일은 **이 스크립트를 올린 Google 계정의 Gmail에서** 나갑니다. 비밀번호는 어디에도 적지 않습니다.
- 신청자 메일 주소는 **내 Google 계정의 구글 시트에만** 저장됩니다. 공개 저장소(GitHub)에는 남지 않습니다.
- 메일을 보낼 Google 계정으로 로그인한 상태에서 진행하세요.

---

## 1. 알림 서버 올리기 (Google Apps Script)

1. **https://script.google.com** → **새 프로젝트**
2. 왼쪽 위 제목을 **오디움 빈자리 알림** 으로 바꿉니다
3. 편집기 내용을 모두 지우고, 아래 파일 내용을 그대로 붙여넣은 뒤 **저장(💾)**
   - https://github.com/khrias86-oss/audium-reservation/blob/main/mailer/Code.gs
     (파일 오른쪽 위 **복사** 버튼)
4. 위쪽 함수 목록에서 **setup** 을 고르고 **▶ 실행**
   - "권한 검토" → 본인 계정 → "Google에서 확인하지 않은 앱"이 나오면
     **고급 → 오디움 빈자리 알림(으)로 이동 → 허용**
     (본인이 만든 스크립트라 나오는 안내입니다. 시트 만들기·메일 보내기·푸시 보내기 권한입니다)
   - 본인 메일함에 **"오디움 빈자리 알림 서버 설정값"** 메일이 옵니다. 그 안의 **열쇠 값**을 3단계에서 씁니다
   - Google 드라이브에 **"오디움 빈자리 알림 — 신청 목록"** 시트가 생깁니다
5. 오른쪽 위 **배포 → 새 배포**
   - 톱니(⚙️) → **웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포** → 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`) 을 복사

> "모든 사용자"여야 공개 페이지에서 신청할 수 있습니다. 그래도 신청자 목록은 밖으로 나가지 않고,
> 알림 발송은 **열쇠**가 있어야만 됩니다.

## 2. GitHub에 알려주기 (값 2개)

**https://github.com/khrias86-oss/audium-reservation/settings/variables/actions**

| 어디에 | 이름 | 값 |
|---|---|---|
| **Variables** 탭 → New repository variable | `MAILER_URL` | 1-5의 **웹 앱 URL** |
| **Secrets** 탭 → New repository secret | `MAILER_KEY` | 1-4 메일의 **열쇠 값** |

웹 앱 URL은 공개 페이지가 부르는 주소라 비밀이 아닙니다(변수). 열쇠는 비밀입니다(시크릿).

## 3. 페이지에 반영하기

**https://github.com/khrias86-oss/audium-reservation/actions/workflows/pages.yml** →
**Run workflow** 한 번. 페이지에 알림 서버 주소가 들어갑니다.

(GitHub Pages가 아직 꺼져 있다면 먼저 **Settings → Pages → Source: GitHub Actions**)

## 4. 확인

1. https://khrias86-oss.github.io/audium-reservation/ 에서 아무 매진 회차를 고르고 **본인 메일**로 신청
2. **"✅ 오디움 빈자리 알림 신청 완료"** 메일이 오면 성공
3. 같은 화면의 **테스트 푸시 보내기**로 ntfy도 확인
4. 확인이 끝나면 **"이 기기에서 신청한 알림" → 알림 끄기**

## 알아두실 것

- **하루 메일 한도:** 개인 Gmail은 Apps Script로 하루 약 100통입니다. 다 쓰면 그날은 메일 대신
  푸시만 갑니다. 한도가 20통 이하로 남으면 신청 확인 메일을 건너뛰고 실제 알림에 남겨 둡니다.
- **누구나 신청할 수 있습니다.** 모르는 사람이 남의 주소를 넣으면 그 사람에게 확인 메일이 가고,
  수신자가 스팸 신고를 하면 Gmail 발송이 제한될 수 있습니다. 이상한 신청이 보이면
  시트에서 그 줄을 지우세요. 필요하면 상한이나 초대 코드를 나중에 켤 수 있습니다.
- **신청 목록 보기·지우기:** 드라이브의 **"오디움 빈자리 알림 — 신청 목록"** 시트.
  줄을 지우면 그 알림이 꺼집니다. 회차 1시간 전이 되면 서버가 알아서 지웁니다.
- **코드를 고치면:** Apps Script에 새 코드를 붙여넣고 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포**.
  웹 앱 URL은 그대로 유지됩니다.
- **열쇠가 새어 나갔다면:** 스크립트 속성의 `NOTIFY_KEY`를 지우고 **setup** 을 다시 실행 →
  새 열쇠를 GitHub 시크릿 `MAILER_KEY`에 넣으세요.
